# POELIO | Fiches de terrain et registre des décisions

**Statut :** modèles vides pour observations futures. Aucun retour participant ni accord de conservation réel n'est prérempli. Ne pas placer les fiches complétées, les coordonnées, les textes personnels ou des exports de navigateur dans le dépôt Git.

Les fiches suivent le [kit de lecture indépendante](INDEPENDENT_READER_FIELD_KIT.md). Un identifiant de séance sans correspondance publique est suffisant ; ne collecter ni nom, ni adresse, ni adresse IP, ni donnée de santé, ni profil personnel par défaut.

## Fiche A — revue littéraire, première exposition

Copier la fiche dans un espace privé *uniquement si* une conservation autorisée est organisée.

```text
POELIO — FICHE A / LECTURE LITTÉRAIRE
Référence de séance : [code non identifiant]
Date : [à renseigner]
Version du site ou commit : [à renseigner]
Œuvre : [register / permutation]
Ordre de présentation : [œuvre seule / œuvre abordée en premier / autre]
Connaissance déclarée du projet avant lecture : [oui / non / inconnu]
Critique initiale terminée avant révélation de la contrainte : [oui / non / incertain]
Note observée : [citation exacte autorisée / paraphrase autorisée / aucune donnée conservée]

1. Mot, image ou phrase retenu — identifier le passage :
[à renseigner]

2. Hypothèse de lecture énoncée spontanément :
[à renseigner]

3. Résistance, faiblesse, ennui ou objection littéraire :
[à renseigner]

4. Modification proposée au texte et contrepartie esthétique :
[à renseigner]

5. Désaccord entre évaluateurs, s'il existe :
[à renseigner]

6. Événement perturbant la première exposition :
[à renseigner]

Décision interne provisoire : [pilote envisageable / révision nécessaire /
reconception majeure / informations insuffisantes]
Raison textuelle vérifiable : [à renseigner]
```

Ne jamais déduire une preuve d'intention d'auteur d'un effet de lecture. La première critique et la critique post-révélation sont enregistrées **séparément**.

## Fiche C — défaut de parcours ou d'accessibilité

Les défauts techniques reproductibles peuvent donner lieu à un ticket public **sans** contenu des lecteurs.

```text
POELIO — FICHE C / INCIDENT
Identifiant interne : [à renseigner]
Version / commit : [à renseigner]
Œuvre et étape : [à renseigner]
Dispositif, navigateur et méthode d'entrée (sans identifiant d'appareil) :
[à renseigner]
Condition de départ :
[à renseigner]
Actions minimales pour reproduire :
[à renseigner]
Résultat attendu :
[à renseigner]
Résultat observé :
[à renseigner]
Impact sur la lecture ou l'autonomie :
[à renseigner]
Reproductibilité : [reproduit / signalé sans reproduction / inconnu]
Gravité : [P0 / P1 / P2 / P3]
Correctif et preuve de vérification : [à renseigner]
```

Gravités indicatives : **P0** divulgation de textes privés ou contenu non autorisé ; **P1** perte de travail, impossibilité de lire ou blocage majeur d'accessibilité ; **P2** incompréhension persistante ou rupture significative du parcours ; **P3** imperfection de présentation sans blocage. La gravité est réévaluée dès qu'une nouvelle preuve apparaît.

## Registre séparé des permissions

Les permissions sont distinctes du jugement éditorial et ne sont jamais déduites d'une participation :

| Question | Réponse à conserver hors dépôt |
|---|---|
| Accord pour la participation à une séance | Oui / non / sans objet |
| Accord pour conserver des notes personnelles | Oui / non / non demandé |
| Accord pour reproduire une citation anonymisée | Oui / non / non demandé |
| Accord pour attribuer une citation à une personne | Oui / non / non demandé |
| Accord pour conserver une création littéraire | Oui / non / non demandé |
| Responsable, emplacement sécurisé, durée de conservation et retrait | Documentés avant collecte |

Le défaut de réponse vaut **absence d'autorisation** pour l'usage concerné. Ne pas conserver de signature ou de pièce d'identité dans le navigateur public. Les permissions nécessaires à une étude institutionnelle sont traitées dans une procédure distincte.

```text
POELIO — REVUE D'UNE ŒUVRE
Œuvre et version : [à renseigner]
Nombre de revues indépendantes effectivement reçues : [à renseigner]
Nombre de séances novices effectivement réalisées : [à renseigner]
Nombre de vérifications d'accessibilité manuelles : [à renseigner]
Ce qui est étayé par des passages précis : [à renseigner]
Désaccords non résolus : [à renseigner]
Défauts bloquants : [à renseigner]
Décision éditoriale : [à renseigner]
Responsable de la décision : [à renseigner]
Prochaine révision vérifiable : [à renseigner]
Ce qui n'a pas été établi : [à renseigner]
```

Aucun total chiffré ne sera présenté comme mesure de qualité littéraire ou effet causal. Les avis négatifs et les cas où le dispositif nuit à la lecture figurent dans la synthèse au même titre que les avis favorables.
